**この `test` ブランチはCodexの自動・模擬検証専用です。実SUUMO・いえらぶへの導入、本番の申告送信、利用者への自動更新は行いません。**

- 唯一の最新テスト版：[`SUUMO-DEV.user.js`](SUUMO-DEV.user.js)（Ver.8.0.3）

- 今回の専用テスト：[tab-runtime-lifecycle.cjs](tests/tab-runtime-lifecycle.cjs)
- 本番の上位版は別ブランチ `dev` のVer.8.0.2、一般版は `main` のVer.8.0です。両方とも変更していません。
- 一括処理の進捗・実行中フラグ・一時的な申告記録はSUUMOタブのsessionStorageに変更。タブを閉じた後の再開・復元は**非対応**。
- 従来の「古い進捗を復旧する」ダイアログは削除。リロードや同じタブ内の正式なページ遷移では継続できる設計です。
- TEST固有の `@namespace` を使用し、`@exclude` で実サイトのTampermonkey自動起動を禁止。自動更新用の`@updateURL`や`@downloadURL`も付けていません。
- `releases/` に見える旧版は**本番ブランチから継承した過去の配布記録**です。テスト版としての配布ファイルは増やしません。
- `latest-dev.json` は本番更新情報を継承したファイルなので、本テスト版のバージョンとは一致しません。テスト配信に使わないでください。
- 不具合が見つかったら**同じtestブランチを更新**し、再テストを行います。検証合格後の本番反映は、ユーザーからの明示的な指示を受けて行います。

> 未検証：新仕様でのCodex全体回帰テストおよび実ブラウザの負荷測定。初期状態の構文・タブ保存機構の独立模擬チェックのみ確認済み。

## 上位版 Ver.8.0.2（2026-10-25／検索時の古い実行状態を安全に診断・復旧）

- いえらぶ連携からSUUMOへ掲載検索中、古い一括申告の実行中フラグが残ると「申告処理へ移行していた」と表示されて検索が止まる問題に対処。
- 検索画面に実行中フラグ・保存進捗・実行工程を表示する診断画面を追加。検索タブ自身に古い担当者タブ情報が残るケースにも対応。
- **自動解除はしない。** 他のSUUMOタブで申告中でなく、未確認の送信もないと操作者がチェック・再確認した場合のみ復旧可能。
- 他タブからの実行中応答を検出した場合、または送信ガード・送信クリック履歴・結果不明の状態・送信処理中の記録・保存領域へのアクセス失敗があれば復旧を禁止。
- 送信と同じWeb Locksの排他区間内で再確認し、最後に一致する古い実行情報だけを解除する。検索情報、会社選択、個人設定、診断情報、送信ガードや送信履歴は消さない。
- Ver.8.0.1までのCodex誤送信防止、検索高速化、UI軽量化、正式な入力・確認・送信・完了経路を維持。一般版 main（Ver.8.0）は凍結。
- 実行フラグ復旧の独立した模擬チェック18項目合格。診断画面の操作を模擬確認し、Node.js再検証用 tests/stale-batch-recovery-v802.cjs を追加。
- 従来の検索状態の模擬テスト tests/search-state-browser.cjs は旧実行フラグの場合に診断画面を期待する仕様へ更新。
- **未検証**：上位版8.0.2でのChromium全体回帰、実Tampermonkeyと実SUUMOの送信処理、Windowsでの復旧操作。全環境での安全性は保証しない。
- 配布用コピー：[Ver.8.0.2](releases/SUUMO-DEV-8.0.2.user.js)

**復旧時の注意：** 診断画面の「古い情報」は実際に誰も処理していないことの証明ではありません。結果不明の送信を復旧機能で回避しないでください。

## Ver.7.54.11（2026-10-25／安全強化の過去検証）

**この節はVer.7.54.11の検証記録です。Ver.8.0.1に安全機構が引き継がれています。**

- 履歴エントリ・タブ・掲載URL・送信IDの紐付けを強化し、古い画面から別物件へ誤送信・誤完了するリスクを抑制。

- いえらぶCLOUDでの上位版ボタン表示を `https://cloud.ielove.jp/rent` とその下層のみに限定。
- 正常10件・混合10件・BFCache復元・複数タブ等、Chromiumを使う模擬テスト58件すべて合格。実SUUMOへの申告POSTは未実施。
- 性能中央値は同一模擬条件で旧1158.3ms、新1159.9ms。実サイト速度を意味しない。
- [詳細な検証と残存リスク](docs/send-safety-browser-check-2026-10-25.md)・[テスト結果](docs/send-safety-browser-results-2026-10-25.json)。

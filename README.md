# SUUMO JJ 一括申告ツール

このリポジトリは SUUMO JJ の一般版と上位版を管理します。

## 配布と更新

| 種類 | 管理場所 | バージョン | 方針 |
| --- | --- | --- | --- |
| 一般版 | [main / SUUMO.user.js](SUUMO.user.js) | **8.1** | 明示的な依頼がある場合のみ更新 |
| 上位版 | [dev / SUUMO-DEV.user.js](https://github.com/Alpha0727/suumo-jj-tool/blob/dev/SUUMO-DEV.user.js) | **7.54.5** | こちらで機能の追加・改善を行う |

一般版の自動更新情報は `main/latest.json`、上位版は `dev/latest-dev.json` を使います。
両者は Tampermonkey の識別情報も異なります。

## 配布済みバージョン

- 一般版の `releases/`：8.1 / 8.0 / 7.50 / 7.49（配布用バックアップ。削除対象は別途判断）

- それ以前のファイルは Git の履歴から確認可能です

## 一般版の保護

一般版8.0は今後変更しない方針です。誤更新防止のため `main` ブランチを GitHub の **Lock branch** で保護する予定です。
この方針の記述だけでは書き込みを物理的に禁止できないため、GitHub側で保護設定が必要です。

## 一般版 Ver.8.1（2026-11-10／基本設定の初回入力必須化）

- 初回インストール時、またはVer.8.0以前からVer.8.1に更新した直後の最初の起動時だけ、基本設定（会社名、担当者名、電話番号、メールアドレス）を空欄に戻す。
- 初回は4項目を埋めて保存するまで、自動入力と一括処理を開始しない。入力不足の項目を表示して基本設定を開く。
- 一度保存した4項目は従来のTampermonkey保存領域で保持。Ver.8.1の再読み込みや次回起動時は消去しない。
- 管理会社名・担当者・TEL・号室・日付設定など他の入力項目はリセットしない。
- JavaScript構文、初回の4項目消去、保存後の再起動時に保持、4項目の必須チェックを模擬検証済み。実サイトの最終送信は未実施。
- 配布版：[Ver.8.1](releases/SUUMO-8.1.user.js)。

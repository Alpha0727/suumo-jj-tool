# SUUMO JJ 一括申告 上位版

- 現行バージョン: **7.54.10**
- 本体: [SUUMO-DEV.user.js](SUUMO-DEV.user.js)
- 上位版自動更新: [latest-dev.json](latest-dev.json)
- バックアップ: [backups/2026-10-20/](backups/2026-10-20/)
- 配布版: [releases/](releases/)

このブランチは**上位版専用**です。一般版は `main` の `SUUMO.user.js`（Ver.8.0）で凍結運用します。

上位版は いえらぶCLOUD との連携・会社別選択・一括指摘機能を維持し、
Ver.7.54.5 で検索結果の全ページ取得・住所/築年月/階数/面積/賃料の5条件照合・会社一覧自動表示を追加しました。

Ver.7.54.6 でSUUMO掲載カードの物件ID・会社名取得を改善しました。
Ver.7.54.7 では検索ワードの住所・築年月による絞り込みを前提に、一覧HTMLの住所・階数・面積・賃料を照合します。築年月の詳細ページ確認を廃止し、候補数に比例した詳細ページ通信を削減しました。
既存の更新URLを壊さずにファイルを整理するため、一般版やいえらぶSPOTの複製はこのブランチから除去しています。
一般版と上位版では Tampermonkey の `@namespace` を分けて管理します。

**バージョン保持**：最新版と直前2版まで。現時点で 7.54.10、7.54.9、7.54.8 を保持しています。
過去の実装は Git の履歴から確認できます。

## Ver.7.54.10（2026-10-24）

- SUUMOの明示的な検索結果0件、住戸条件一致0件・掲載会社0件は再検索せず自動スキップ。掲載終了画面も自動スキップ。
- 送信前の通信・読取・フォーム・画面遷移失敗は初回を含め最大3試行、再試行間隔は各500ms。3回失敗時はエラーを保存して次へ。
- 最終送信後に完了が確認できない場合は「要確認」を記録し、二重送信をせず次の掲載へ。手動URL一括処理にも送信ガードを追加。
- 処理終了後は問題があった掲載のみの結果画面を表示。「エラー内容をコピー」で診断用テキストをコピー可能。管理会社情報やメール・電話・認証情報は含めない。
- 作業前のバックアップ：[Ver.7.54.9保存](backups/2026-10-24-before-7.54.10/)。
- 仕様・模擬検証・未検証条件：[エラー処理レポート](docs/error-handling-7.54.10.md)。
- コード構造の階層分けは行っていない。SUUMO実サイトでの申告送信は未検証。

## Ver.7.54.9（2026-10-24）

- **送信前のツール独自の二段階確認（各1秒）を廃止**し、フォーム準備後の単一300ms自動進行に変更。
- 自動入力結果の一致確認、必須項目チェック、物件情報の対応確認、SUUMOの正式な内容確認画面、最終送信前250ms、送信結果が不明なときの二重送信防止は維持。
- 旧版の`INPUT_CONFIRM`ステージから復帰した場合は新しい`INPUT_READY`へ正規化し、古いタイマーの位相を再利用しない。
- 画面復帰時の直接送信を廃止し、通常の`handleConfirmPage()`経路に統一。
- 模擬テスト：送信開始11ケース、SUUMO確認画面5ケースを実施（実サイト未検証）。
- 修正前コード・更新設定の保存先：[バックアップ](backups/2026-10-24-before-7.54.9/)。
- コード階層分けと安全な段階的移行の提案：[コード構成見直し案](docs/code-structure-plan.md)。配布用ファイルは引き続き単一の`SUUMO-DEV.user.js`。

## Ver.7.54.8（2026-10-24）

- 検索ページ取得の240ms待機を「通信完了後の固定待機」から「通信開始間隔の下限」に変更。並列取得はせず、通信・解析にかかった時間を待機に重複加算しません。
- 会社リンクから名称を取得できるときは、予備の会社名DOM探索を省略。セル一覧の配列コピーとバッチ開始時の重複保存も削減。
- 12秒タイムアウト、最大3試行、750ms/1500msの再試行待機、Retry-After尊重を実装。取得中に対象物件・実行状態が変わった場合や、不明な空ページ・ページ循環を検出した場合は停止。
- Ver.7.54.7の検索・照合条件、全ページ取得、選択UI、除外設定、保存キー、申告の確認・安全待機・二重送信防止は維持。
- ChromeコンソールのVerboseを有効にすると「性能」で通信・HTML解析・照合・会社集計などの所要時間を確認できます。既存の「工程」ログでは画面遷移や全物件完了・選択画面表示を追跡できます。
- 旧版と更新設定のバックアップ：[backups/2026-10-24-before-7.54.8/](backups/2026-10-24-before-7.54.8/)。
- 検証内容・採用しなかった改善案・計測条件：[性能検証レポート](docs/performance-7.54.8.md)。実サイトへの申告送信は実施していません。

検証の再実行（Node.js、Playwright、Chromiumが必要）：

```sh
node tests/optimization.cjs
node tests/memory.cjs
```

クラウド環境では既存のPlaywrightと `/usr/bin/chromium` を使用しました。他の環境ではPlaywrightを用意し、必要に応じて `CHROMIUM_PATH` を指定してください（機能テスト）。テストのGM APIとHTML・通信は模擬で、Tampermonkey拡張自体と実サイトへの接続は未検証です。

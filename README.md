# SUUMO JJ 一括申告 上位版

- 現行バージョン: **7.54.6**
- 本体: [SUUMO-DEV.user.js](SUUMO-DEV.user.js)
- 上位版自動更新: [latest-dev.json](latest-dev.json)
- バックアップ: [backups/2026-10-20/](backups/2026-10-20/)

このブランチは**上位版専用**です。一般版は `main` の `SUUMO.user.js`（Ver.7.50）で凍結運用します。

上位版は いえらぶCLOUD との連携・会社別選択・一括指摘機能を維持し、
Ver.7.54.5 で検索結果の全ページ取得・住所/築年月/階数/面積/賃料の5条件照合・会社一覧自動表示を追加しました。

Ver.7.54.6 でSUUMO掲載カードの物件ID・会社名取得を改善しました。
既存の更新URLを壊さずにファイルを整理するため、一般版やいえらぶSPOTの複製はこのブランチから除去しています。
一般版と上位版では Tampermonkey の `@namespace` を分けて管理します。

**バージョン保持**：最新版と直前2版まで。現時点で 7.54.6、7.54.5、7.54.4 を保持しています。
過去の実装は Git の履歴から確認できます。

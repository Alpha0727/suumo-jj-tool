# SUUMO JJ 上位版 Ver.7.54.10 — 0件・掲載終了・エラー処理

更新日：2026-10-24

## 自動スキップ

- SUUMO検索結果ページに「条件にあう物件がありません」「賃貸0件」等の明示的な0件表示があり、実際の物件カードがない場合は再検索せず次の物件へ。
- 全検索ページを取得し、住所・階数・面積・賃料に一致する住戸が0件の場合も、掲載会社0件として次へ。
- SUUMO詳細ページに「当サイトへの掲載が終了したためご覧いただけません」等の案内があり、対象掲載に対応すると判断できた場合は申告せず次へ。
- 「不動産会社0件」という表示**だけ**を根拠に検索0件とはみなさない。
- 読み込み失敗・空白HTML・掲載会社の取得失敗は、0件と混同しない。

## エラー時の最大試行回数

- 送信前の掲載リンク取得・フォーム準備・確認画面取得・検索/会社情報の読取失敗は初回を含めて最大3回。
- 自動再試行間隔は500ms固定（1回目失敗後500ms、2回目失敗後500ms）。
- フォーム準備では既存の最大3回と重複させず、3回失敗で記録して次へ。
- 検索ページがエラーになった場合は再取得を試すが、SUUMOの明示したRetry-Afterが500msより長い場合や認証・形式エラー等は無理に連続アクセスしない。
- 処理失敗が3回続いた掲載は送信しないでスキップし、理由を記録。
- サイト全体の認証・内容判定が不明な場合は、成功や0件と決めつけない。

## 最終送信と二重送信の保護

- SUUMO本来の内容確認画面を維持し、最終送信前250msも維持。
- 最終送信のクリック直前に、対象URL・インデックス・送信状態を保存する。
- 送信後に完了画面を確認できない場合は「送信結果不明・要確認」と記録して次へ。
- 送信結果不明の掲載は**自動再送信しない**。いえらぶ連携・手動URL一括処理の両方を保護。
- 画面復帰時や手動再実行・スキップ操作でも送信状態を確認する。

## 結果画面とコピー

- 成功した掲載は最終結果一覧に表示しない。問題がある掲載のみ表示。
- エラー一覧の「エラー内容をコピー」は、エラーの工程、対象番号、内容、試行回数、対応、日時、公開掲載URL、スクリプトのバージョンを整理した日本語テキスト。
- 会社名、管理会社情報、フォーム入力値、認証情報、メールアドレス、電話番号を含めないようにする。
- 公開掲載URL以外の任意URLは削除・伏せ字にする。

## 検証と未検証

コード構文検査と関数単位の模擬テスト：

- SUUMOの0件画面・不動産会社のみ0件・通常ページ・掲載終了画面の判別
- 掲載終了/0件を誤って認定しないこと
- 最大3試行と再試行待機500ms×2回
- フォームエラーと未確認送信の再試行/次掲載遷移を分離
- 送信済み可能性のある掲載を二重送信しない
- GPT共有用コピー内容の個人情報・URLのマスキング

**実際のSUUMOへの申告送信は行っていない。** 実ページの全バリエーション、ログイン・Cookie・通信状態による差異は未検証。
